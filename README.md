# Tic-Tac-Toe
A console Tic-Tac-Toe game using C++. As the game is run, a console screen appears and asks to click enter once ready. Then, a grid of 9×9 dots appears, and the program asks to enter a number from 1 to 9. Number 1 reprsentes the top-left dot, and number 9 represents the bottom-right dot. The numbers increase from left to right and from top to bottom.
